# v3.0.0 · 评价标准改进与客服质检 Agent

将原先的批量评估系统升级为本地客服质检助手：自然语言任务驱动真实千问工具调度，支持批量评估、单条解释、风险查询、人工分歧、业务证据补充和报告导出。

评价标准增加任务与情境判断、0–4分锚点、轻微/明显缺口和一致性复核。保留事实证据弃权、风险门控及参考答案隔离。

同样20条数据和冻结标签上，Micro Precision 59.5%→75.0%，Recall 73.3%→60.0%，F1 0.6567→0.6667。误报减少但漏检增加；不以暂定均分升高证明评估器更准确。完整原始输出、旧版与分歧均保留。

验证：41项工程测试、5轮真实 Agent 验收、12项静态报告浏览器检查及13项 Agent 浏览器检查通过。10条开发构造样例通过34/34项行为断言。所有结果为开发验收，不是独立业务盲测。

运行：配置本地 `.env`，执行 `python serve.py`，访问 `http://127.0.0.1:8765`。评估 CLI 仍保留。核心仅依赖 Python 标准库；无模型配置时可以查看已生成的静态报告。

边界：本地单人原型；会话状态在内存中，重要结果请导出。未知事实需真实业务证据；没有自动认证来源、生产订单操作或实际周期调度。凭据和模型缓存不随版本发布。
